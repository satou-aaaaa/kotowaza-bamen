# ことわざ場面あて

ふだんの場面を読んで、それにぴったりのことわざを4つから選ぶ1日5問のゲーム。前もって知らなくても、遊ぶうちにことわざの意味と使いどころを覚えられます。時間制限なし。

- 遊ぶ: https://satou-aaaaa.github.io/kotowaza-bamen/
- 今日の5問（人づきあい・失敗と用心・努力と運を1つずつ＋ふつう1・むずかしい1）はだれでも同じで1日1回。上級（むずかしい3問・場面2つだけ）、練習（何度でも・まだ当てていないことわざから）、とことん（全100のことわざを次々に）があります。
- 手がかりは3つまで（場面一・場面二・ことわざに入っている言葉）。少ない手がかりで当てるほど★が多くなります。まちがえても選び直せます。
- 当てたことわざは「ことわざ帳」に書きとめられ、場面・意味・出典を読み返せます。
- 見やすさの設定（読みやすい文字・色の見分け・動きを減らす・読み上げ）と、記録を別の端末へ移す「引き継ぎ」があります。

## 意味のもと（出典）

ことわざごとの出典は `data.js` の `src` と、ゲームの中（当てたあと・ことわざ帳）に書いてあります。

- 意味：『デジタル大辞泉』（小学館）、『実用日本語表現辞典』
- 意味の取りちがえ：文化庁「国語に関する世論調査」平成22年度（情けは人のためならず）・平成24年度（気が置けない）

場面の文はこのゲームのために書いた例です。まちがいに気づいたら、感想のフォームで教えてください。

## 記録と通信

記録は遊ぶ人のブラウザにだけ残り、ゲームから自動で外へ送ることはありません。例外は2つ：文字（Google Fonts）を読み込むとき、まだ端末に保存が無ければ Google に IP アドレスが届きます。「Xで投稿」「LINEで送る」「結果をシェア」を押したときだけ、結果の文が選んだ先に渡ります（ことわざは入りません）。

## 開発

```bash
bash scripts/setup.sh   # 最初に一度
node qa/run.mjs         # 検査（CI と同じ）
```

問題のもとは `data.js`（決まりは AGENTS.md）。
